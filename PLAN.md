# Планер проебщика: аудит и план апгрейда

Исходник: AI Studio (React 19 + Vite + Firebase), всё в одном `src/App.tsx` (~1 900 строк). Деплой: Vercel `my-dashboards`, база: Firestore в отдельном проекте `gen-lang-client-0262263058` (кроме планера там никого нет).

---

## 1. Что не так сейчас

### Безопасность
- Любой может войти анонимно, записать себе в `user_links_anon` чужой uid и читать/удалять чужие задачи. `link_codes` и `user_links` открыты всем на чтение и запись.
- Ключ Gemini лежит в браузерном бандле.
- Telegram-пользователь не проверяется: `initDataUnsafe` берётся на веру.

### Баги
- Пропущенная рутина и просроченная задача не видны «сегодня», только красная точка на прошлом дне.
- «Каждый месяц» привязан к дате создания, день выбрать нельзя: из-за этого счётчик и собака заведены через 16–17 ручных дат.
- Кнопки «изменить»/«удалить» видны только при наведении (на телефоне их нет), в «Завершено» удаление не появляется вообще.
- Удаление без подтверждения, подзадачи нельзя отметить или добавить руками.

### Бот
- Жил в Google Colab, поэтому работал только пока открыт блокнот. Код потерян: пишем заново на чистом боте `@Willy_Billi_bot`.

## 2. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Хостинг | Vercel, как сейчас | нагрузка < 1% лимитов Hobby |
| Данные | остаются в Firestore | в Supabase свободных бесплатных проектов нет, а `mailflow` рабочий |
| Сервер | одна функция `api/router.ts`, как в retention | лимит Hobby: 12 функций на деплой |
| Расписание | внешний пинг `/api/cron` раз в 5 минут (cron-job.org) | cron Vercel на Hobby только раз в день |
| Дизайн | семья MailFlow/Retention: Onest + Unbounded, токены `ground/paper/ink/moss…`, карточки 24px; свой градиент «Слива», у «Личного» — свой яркий | третий член семьи, но не спутать |
| Тёмная тема | убираем | в семье её нет |
| Язык | русский, и в дашборде, и в боте | |
| Время | везде `Europe/Kyiv` (сама переводится на летнее/зимнее) | |
| Нейросети | убраны полностью: брифинг, «Память», AI-подзадачи, Gemini | владелец не хочет AI-ответов; заодно закрыта утечка ключа |
| Название | «Планер проебщика» можно сменить, решаем на этапе редизайна | |
| Перетаскивание в календаре | пока нет | самая дорогая часть, заменяем кнопками «на завтра / на день / на время» |

## 3. Этапы (каждый — отдельный PR с превью Vercel)

1. **Безопасность и сервер.** ✅ PR `feat/security-telegram-auth`. Правила «только владелец». Удалены коды, `link_codes`, `user_links_anon`, анонимный вход и Gemini. Вход из Telegram: сервер проверяет подпись `initData` и выдаёт Firebase custom token на Google-uid из `user_links` (старые привязки работают). Новая привязка: в браузере «Подключить Telegram» → `t.me/Willy_Billi_bot?start=<одноразовый токен>`.
2. **Бот.**
   - 10:00 по Киеву — что на сегодня и что просрочено.
   - За час до дедлайна — напоминание; в дедлайн — «время вышло». Кнопка «Выполнено» закрывает задачу.
   - Отчёт по спринту: спринт = 14 дней с понедельника по воскресенье, отчёт в пятницу второй недели. Точка отсчёта: спринт 19.10.2026–01.11.2026, отчёт 30.10.2026. Бот присылает утром в пятницу простой список без нейросети: «Сделано за спринт», «Не сделано / просрочено», «Запланировано на следующий спринт». Текст «Достижения / Проблемы / Фокус» пишет сам владелец. Плюс команда `/report` на любой день.
3. **Модель данных.** Повторы: каждые N дней/недель/месяцев, дни недели, число месяца, до даты. Старые `dueDates` продолжают работать без миграции. Блок «Не сделано» сверху дня. «Заметка → задача», «дублировать задачу». Поле `notified` для бота.
4. **Редизайн и календарь.** Неделя с сеткой по часам (компьютер), день-лента (телефон), месяц-обзор.

## 4. Что делает владелец (секреты в чат не присылать)
- Удалить утёкший ключ Gemini в Google AI Studio (он больше не нужен).
- Firebase Console → сервисный аккаунт → ключ → в Vercel env.
- Токен бота → в Vercel env.
- Аккаунт на cron-job.org, одно задание на `/api/cron`.
